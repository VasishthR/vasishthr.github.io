02 — Why This Book Exists

Not a syllabus rewrite. A record of what actually worked.

01

The Problem

Java felt like a list of code to copy, not a subject to understand. It worked, until the exam asked something the textbook hadn't shown.

02

The Turning Point

I stopped memorising and started asking why. Once the logic made sense, the code stopped needing to be memorised — I scored 97.6% in the ICSE 2025 board exam, including a perfect 100 in Computer Applications.

03

The Book

Think. Code. Score. is that method, in the order I wish someone had taught it to me. Every reader gets the shortcut I had to find on my own.

I didn't understand Java until I stopped trying to memorise it and started asking why it worked. — Vasishth Rungta, Author
